## 四、简答题（共6题）

### 99. 简述折线图、柱状图、饼图各自最适用的数据场景

**答案**：
1. **折线图**：面向连续时间序列数据，核心展示数据变化趋势和波动幅度
2. **柱状图**：面向离散分类数据，直观对比不同类别之间的数值大小
3. **饼图**：用于占比分析，展示各分类占整体的百分比关系，类别不宜过多（建议不超过6-7个）

*解析*：图表选型是数据可视化的核心能力。折线图强调趋势，柱状图强调对比，饼图强调占比。选错图表类型会误导读者。

---

### 100. 简述柱状图与直方图的三大核心区分点

**答案**：
1. **X轴含义**：柱状图X轴为文字分类标签（离散）；直方图X轴为连续数值区间（分箱）
2. **柱子间距**：柱状图柱子之间存在明显间隔；直方图柱子紧密无空隙
3. **使用目的**：柱状图用于对比各类别数值大小；直方图用于展示数据分布频次/频率

*解析*：这是常考易混点。柱状图=分类对比，直方图=分布形态。虽然外观相似，但本质完全不同。

---

### 101. 简述南丁格尔玫瑰图 roseType 两种模式（radius、area）的区别与适用场景

**答案**：
- **roseType: 'radius'**：扇形圆心角与数据占比挂钩，半径代表数值大小；适合同时查看各分类占比+具体数值（如各产品销售额及市场份额）
- **roseType: 'area'**：所有扇形圆心角度数完全一致，仅依靠半径区分数值；无占比含义，仅单纯对比数据大小（如各城市月度降水量）

*解析*：玫瑰图是南丁格尔发明的经典图表。radius模式=饼图变体（角+径双编码），area模式=极坐标柱状图（仅径编码）。

---

### 102. 简述堆叠柱状图的作用与实现方法

**答案**：
- **作用**：①直观展示每个分类下各子项数值；②可查看每个分类数据总和，对比分类总体大小
- **实现方法**：多个 series 系列配置相同的 stack 字符串值，拥有相同 stack 的系列会垂直堆叠在一起；不同 stack 分组会分开并列展示

*解析*：在 ECharts 中设置 `series: [{type:'bar', stack:'total', data:[...]}, {type:'bar', stack:'total', data:[...]}]` 即可实现堆叠。Matplotlib 则需多次调用 bar() 并传入 bottom 参数。

---

### 103. 简述 Matplotlib 与 ECharts 的核心区别及适用场景

**答案**：
- **运行环境**：Matplotlib 基于 Python 本地运行，输出静态图片；ECharts 基于 JavaScript，浏览器运行，生成可交互网页图表
- **交互能力**：Matplotlib 图表无交互功能；ECharts 支持缩放、筛选、悬浮查看数据等交互操作
- **适用场景**：Matplotlib 用于数据分析、科研绘图、离线出图、批量生成；ECharts 用于网页大屏、数据可视化平台、动态数据展示
- **开发语言**：Matplotlib 原生 Python；ECharts 原生 JavaScript，可通过 Pyecharts 在 Python 中调用

*解析*：两者互补而非竞争——Matplotlib 做分析探索和论文图表，ECharts 做产品级交互式可视化。

### 109. 【整段代码·Pyecharts】使用 Pyecharts 绘制学科成绩占比饼图，保存为 HTML

要求：语文85、数学92、英语88、物理78，开启图例和悬浮提示，导出 HTML 文件。

**答案**：
```python
from pyecharts.charts import Pie
from pyecharts import options as opts

data = [("语文", 85), ("数学", 92), ("英语", 88), ("物理", 78)]

pie_chart = (
    Pie()
    .add(series_name="分数", data_pair=data)
    .set_global_opts(
        title_opts=opts.TitleOpts(title="学科成绩占比饼图"),
        legend_opts=opts.LegendOpts(is_show=True)
    )
    .set_series_opts(tooltip_opts=opts.TooltipOpts(trigger="item"))
)

pie_chart.render("成绩饼图.html")
```

*解析*：Pyecharts 采用链式调用，Pie() → .add() 添加数据 → .set_global_opts() 全局配置 → .set_series_opts() 系列配置 → .render() 输出 HTML。这是 Python 开发者使用 ECharts 的便捷方式。
